# Mindful

A responsive psychologist discovery and booking product demo designed for India.

## Features

- Search and filter six fictional profiles and Anunandha’s user-provided listing by concern, language, session mode, city, and fee.
- View profiles and save a shortlist locally.
- Book a demo session in IST, with duplicate-slot prevention in the current browser.
- Reschedule and cancel demo appointments.
- Read first-session guidance and product limitations.
- Responsive desktop and mobile layouts; keyboard-accessible native dialogs.

## Scope

This is a static interactive demo. It does not reserve real consultations, verify credentials, process payments, create video meetings, authenticate patients, or send messages. Anunandha’s name, languages, city, experience, and fee were supplied by the site owner; qualifications, specialties, and session formats remain to be confirmed. Other profiles, qualifications, and prices are fictional examples. Portraits are illustrative Unsplash images. Names/nicknames and demo bookings are stored in localStorage in the visitor's browser; do not enter sensitive health information.

## Preview

Serve the repository root with any static HTTP server. No build or installation is required.

## Production roadmap

Connect a verified practitioner roster and scheduling service, implement patient and clinician access with secure server storage, integrate payments and video, and establish privacy, consent, cancellations, and provider onboarding workflows before accepting real consultations.
